# Chapter artwork batch pipeline

This release gate tracks all 40 chapter illustrations.

## Production rules

- One chapter = one single 16:9 scene.
- No collage, grid, montage, or storyboard output.
- Contemporary Iranian setting and recurring character identity are mandatory.
- Girls and women use contemporary modest hijab.
- Chapters where Nino is missing must not depict him physically unless the manifest explicitly allows a lookalike.
- No raster asset ships until it is visually reviewed and added to the approved list.
- Exact duplicate raster files fail CI.

The approved list currently contains the three reviewed production rasters. The remaining 37 chapters stay pending until they pass visual QA. Batch imports must update the manifest and pass this gate before merge.
