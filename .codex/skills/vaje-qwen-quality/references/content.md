# Content and editorial workflow

Current repository content, story canon, prerequisite rules, and validators are authoritative.

## English

Require:
- grammatical correctness
- natural contemporary usage
- clear intended sense
- level-appropriate surrounding language
- consistency of tense, reference, and story chronology
- low template repetition

## Persian

Require:
- accurate meaning
- natural Iranian Persian
- correct register for the learner
- consistent terminology where consistency helps
- no unnatural word-for-word translation simply to mirror English syntax

## Vocabulary examples

A flashcard example should:
- demonstrate the target sense clearly
- avoid unnecessary difficult vocabulary
- be independently understandable
- not create a second plausible translation that undermines testing

## Chapter change protocol

For any changed chapter/passage:
1. read enough preceding/following context to preserve continuity
2. verify target/new-word prerequisites
3. validate English and Persian sentence pairs
4. check every dependent comprehension item
5. check distractor uniqueness
6. run relevant current validators
7. manually spot-check rendered content where formatting/audio matters

## Cultural/editorial rules

Read current repository canon/validators before modifying culturally constrained content. Do not hard-code older remembered rules over newer repository truth.

Automation may detect problems, but it cannot invent native-speaker review completion.
