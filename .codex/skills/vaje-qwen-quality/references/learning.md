# Learning and assessment

The objective is durable English vocabulary learning for Persian-speaking learners. Engagement features must not counterfeit mastery.

## Preserve the intended acquisition sequence

Unless the current canonical policy intentionally changes it:

1. teach new vocabulary directly
2. provide accurate pronunciation
3. require productive/written meaning evidence
4. require listening evidence without leaking the target form
5. unlock contextual story work only after required preparation
6. use later spaced retrieval for durable evidence
7. remediate actual errors rather than repeating everything

Do not reintroduce default "guess before teach".

## Mastery

Mastery should depend on genuinely independent evidence:
- across time, not only same-session correction
- across relevant retrieval modes
- with productive recall where policy requires it
- with adequate recent accuracy/stability
- without date manipulation alone creating evidence

Immediate retry after feedback is relearning, not spaced success.

## Assessment integrity

For each item:
- exactly one defensible answer
- prompt contains enough information
- distractors are plausible but not co-correct
- no accidental answer clues
- no homophone collision in audio-only meaning choices
- typed normalization accepts harmless orthographic variation without accepting different meanings
- comprehension answer is supported by the supplied passage/audio, not outside knowledge

When editing a passage, re-check all dependent questions.

## Spacing/scheduler changes

Test:
- first learning event
- failure/relearning
- same-day retry
- next-day/delayed retrieval
- timezone/day boundary
- stale tabs/multiple devices where supported
- very weak and very strong items
- maximum/minimum interval guards

## Policy numbers

Thresholds, sample sizes, spacing rules, forgiveness rules, and exam structure belong in the repository's canonical policy source. Do not scatter replacement constants.

If a number is heuristic rather than empirically calibrated, label it as such in project evidence rather than implying validation.
